# TT League

Мобильная лига настольного тенниса без выбывания. Приложение: https://siblife54-dot.github.io/tt-league/

## Как пользоваться

1. Добавьте профили игроков, можно несколько имён через запятую.
2. Выберите 4–8 участников и начните турнир. Программа назначит случайные стартовые пары.
3. Введите счёт текущего матча. Переходы и новая пара появятся автоматически.
4. Завершите турнир по кнопке. Итоги автоматически остаются в истории.
5. «Скопировать для ChatGPT» выдаёт Markdown с результатами всех матчей и статистикой. JSON сохраняет всю базу для восстановления.
6. В истории можно удалить тестовый турнир. Его матчи, очки сезона и ачивки исчезнут из расчётов; профили сохранятся.

## Правила версии 1

Одна партия до 11, после 10:10 разница 2. Открытие: победитель Gold, проигравший Silver. При нечётном составе последний в сохранённой случайной жеребьёвке после открытия получает технический проход в Gold без очков.

После открытия победа поднимает на один уровень, поражение опускает; Gold — потолок, Bronze — нижний уровень. Очки за победу по уровню ДО матча: старт 2, Gold 3, Silver 2, Bronze 1. Поражение не отнимает очки.

Самая многочисленная группа получает следующую игру. В ней выбираются давно ожидающие. После N−1 пропущенных матчей ожидание получает приоритет. Если игрок один, соперник берётся из ближайшей непустой группы. В таком матче каждый переходит относительно собственного прежнего уровня; очки победителю — за его прежний уровень. При равном ожидании предпочтение меньшему числу игр, затем меньшему числу повторных встреч и жеребьёвке.

Места: сумма турнирных очков, затем процент побед, средняя разница игровых очков за матч, затем сохранённая жеребьёвка. Очки сезона за места 1–8: 15, 10, 7, 5, 4, 3, 2, 1. Эти начальные настройки видны перед стартом. Число матчей может различаться.

Завершение доступно после стартовых матчей. Следующая предложенная пара при завершении не учитывается. Для ошибочного результата есть отмена последнего счёта; исправления давно сыгранных матчей с зависимыми переходами в первой версии не поддерживаются.

## Хранение

Без сервера и сторонних сервисов. IndexedDB хранит профили, турниры и результаты в этом браузере. GitHub не получает данные игроков. Очистка данных сайта или потеря устройства могут удалить историю — скачивайте JSON. Импорт полностью заменяет базу, предварительно предлагает скачать её и сохраняет предыдущую базу локально. Нет синхронизации устройств.

Рейтинг, личные встречи и достижения вычисляются заново по сохранённым завершённым турнирам. Отчёты после удаления тестов отражают оставшуюся историю. Старые данные из ChatGPT автоматически не загружены.

После первой успешной загрузки приложение кэшируется для работы без сети. Новая версия активируется после закрытия старых вкладок. На iPhone: «Поделиться» → «На экран Домой»; в поддерживающих установку браузерах Android — установка приложения в меню браузера.

## Разработка и публикация

Статические HTML/CSS/JavaScript-модули, без сборки и внешних runtime-зависимостей. `domain.js` — чистые правила, `storage.js` — IndexedDB, `app.js` — интерфейс. `npm test` запускает тесты Node.js; `npm run check` проверяет синтаксис. Для локального просмотра: `python -m http.server 4173` из корня репозитория.

GitHub Pages: ветка `main`, каталог `/ (root)`. Все пути относительные, приложение работает в `/tt-league/`. При обновлении ресурсов меняйте версию кэша в `sw.js`. Не публикуйте резервные копии реальных турниров в репозитории.
